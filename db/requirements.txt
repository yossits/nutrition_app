# Dependencies for the db/ import pipeline only.
#
# Deliberately NOT merged into the repository-root requirements.txt. The spike
# must stay runnable with no network and no key, and its file says so in as
# many words. A database driver in that list would make `pip install -r
# requirements.txt` pull a Postgres client for someone who only wants to run
# run_spike.py — which breaks exactly the property the root file protects.
#
#   pip install -r db/requirements.txt
#
# psycopg is the only third-party import in db/: 03_load_source.py and
# 04_transform.py both use it, and nothing here needs openpyxl — the four
# source files are read as CSV.
#
# The [binary] extra ships a prebuilt libpq, so Windows does not need a local
# Postgres install or build toolchain. Without it, `import psycopg` fails at
# runtime with a libpq error rather than at install time.
#
# Lower bound, not a pin — the same convention the root file uses for requests.
# 3.1 is where the psycopg3 API these scripts use settled; block 1 was run and
# verified against 3.3.4 on 29.08.2026.
psycopg[binary]>=3.1
